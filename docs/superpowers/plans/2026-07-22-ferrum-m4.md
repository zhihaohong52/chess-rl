## Orientation (read once before Task 1)

**Where things are.** All search code is in one file, `ferrum/src/search.rs`, with tests in its `#[cfg(test)] mod tests`. Key existing items the tasks reference by name:

- `struct Searcher { pub tt, nodes, deadline, stopped, history: Vec<u64>, killers: [[Move;2];MAX_PLY], eval: EvalKind }` — `history` is the **position-hash list for repetition**, NOT move ordering. Do not reuse that field for history heuristics; add new fields.
- `fn negamax(&mut self, b: &mut Board, depth: i32, mut alpha: i32, beta: i32, ply: i32) -> i32` — the main search. `MATE = 30_000`, `MATE_BOUND = MATE - 1_000`, `MAX_PLY = 128`.
- `fn order_moves(&self, b, moves: &mut [Move], tt: Move, ply: i32)` — SEE/killer ordering; quiets currently score `0`.
- `fn make_move(&mut self, b, m) -> Undo` / `fn unmake_move(&mut self, b, m, undo)` — wrap `Board::make`/`unmake` and thread the NNUE accumulator. Use these, never raw `b.make` in the search tree.
- `fn qsearch(&mut self, b, mut alpha, beta, ply) -> i32`.
- The LMR block is `search.rs:377-391`; RFP `:313-315`; NMP `:321-336`; LMP `:355-361`; futility `:363-369`; the TT-probe/cutoff `:295-307`; static-eval computation `:309`.

**Move / board API** (`moves.rs`, `board.rs`, `types.rs`):
- `Move` is `Copy + PartialEq`; `Move::NONE`, `m.from() -> u8`, `m.to() -> u8`, `m.flags() -> u16`, `m.is_capture()`, `m.is_promo()`, `m.promo_pt() -> usize` (2..5).
- `b.piece_on(sq) -> Option<usize>` returns a 0..12 piece index; `%6` gives the piece type 0..5 (`PAWN=0 KNIGHT=1 BISHOP=2 ROOK=3 QUEEN=4 KING=5`). `pc(color, pt) -> usize` builds the 0..12 index. `b.side: Color` (`Color::idx() -> 0/1`).
- `z()` returns the `Zobrist { piece: [[u64;64];12], .. }` singleton; `zb.piece[p][sq]` is the per-(piece,square) key already used by the main hash.

```rust
/// Move-ordering history (M4 B1). Three independent gravity-updated tables:
/// main quiet `[color][from][to]`, 1-ply continuation `[prev_piece_to][cur_piece_to]`
/// (piece-to index = piece(0..12)*64 + to(0..64)), and capture `[piece][to][captured_pt]`.
/// Entries stay in (-MAX, MAX) via the gravity update. Not the `Searcher::history`
/// field (that is the repetition hash list).
pub struct History {
    main: Vec<i32>,    // len 2*64*64
    cont: Vec<i32>,    // len 768*768
    capture: Vec<i32>, // len 12*64*6
}
impl History {
    pub const MAX: i32 = 16_384;
    pub const BONUS_CAP: i32 = 1_200;

    pub fn new() -> Self {
        History { main: vec![0; 2 * 64 * 64], cont: vec![0; 768 * 768], capture: vec![0; 12 * 64 * 6] }
    }
    pub fn clear(&mut self) {
        self.main.iter_mut().for_each(|e| *e = 0);
        self.cont.iter_mut().for_each(|e| *e = 0);
        self.capture.iter_mut().for_each(|e| *e = 0);
    }
    /// Depth-scaled cutoff bonus, capped.
    pub fn bonus(depth: i32) -> i32 { (16 * depth * depth).min(Self::BONUS_CAP) }

    fn apply(entry: &mut i32, delta: i32) {
        // Gravity: pulls toward 0 proportionally so |entry| stays < MAX.
        *entry += delta - *entry * delta.abs() / Self::MAX;
    }

    fn main_idx(c: Color, from: u8, to: u8) -> usize { (c.idx() * 64 + from as usize) * 64 + to as usize }
    pub fn quiet(&self, c: Color, from: u8, to: u8) -> i32 { self.main[Self::main_idx(c, from, to)] }
    pub fn update_quiet(&mut self, c: Color, from: u8, to: u8, delta: i32) {
        let i = Self::main_idx(c, from, to); Self::apply(&mut self.main[i], delta);
    }

    pub fn cont(&self, prev: usize, cur: usize) -> i32 { self.cont[prev * 768 + cur] }
    pub fn update_cont(&mut self, prev: usize, cur: usize, delta: i32) {
        let i = prev * 768 + cur; Self::apply(&mut self.cont[i], delta);
    }

    fn cap_idx(piece: usize, to: u8, victim_pt: usize) -> usize { (piece * 64 + to as usize) * 6 + victim_pt }
    pub fn capture(&self, piece: usize, to: u8, victim_pt: usize) -> i32 { self.capture[Self::cap_idx(piece, to, victim_pt)] }
    pub fn update_capture(&mut self, piece: usize, to: u8, victim_pt: usize, delta: i32) {
        let i = Self::cap_idx(piece, to, victim_pt); Self::apply(&mut self.capture[i], delta);
    }
}
impl Default for History { fn default() -> Self { Self::new() } }
```
Add `use crate::types::Color;` items already imported via `types::*` at the top — no new import needed.

static LMR: OnceLock<[[i32; 64]; 64]> = OnceLock::new();
/// Base LMR reduction `floor(0.77 + ln(d)*ln(m)/2.36)`, precomputed for d,m in 0..64.
fn lmr_reduction(depth: i32, moves: i32) -> i32 {
    let t = LMR.get_or_init(|| {
        let mut t = [[0i32; 64]; 64];
        for d in 1..64 {

            }
        }
        t
    });

}
