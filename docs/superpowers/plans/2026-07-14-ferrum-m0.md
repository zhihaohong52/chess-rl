**Goal:** A from-scratch Rust UCI chess engine (`ferrum`) with perft-verified move generation, alpha-beta + quiescence + transposition-table search, material+PST evaluation, and a `bench` checksum — playable in any GUI, ~1800–2000 strength.

**Architecture:** Single binary crate, std-only (no dependencies). Bitboard position with make/unmake; pseudo-legal generation filtered by king-safety after make; ray-table sliding attacks (magics deferred to M1 as a bench-gated perf patch); iterative-deepening negamax. Perft vectors are the correctness oracle for all board/movegen work.

**Tech Stack:** Rust (stable, 2021 edition), cargo test, fastchess (self-play smoke).

**Spec:** `docs/superpowers/specs/2026-07-14-ferrum-nnue-engine-design.md` (chess-rl repo)

**Crate location:** `ferrum/` subdirectory of the chess-rl repository (user decision 2026-07-14: no separate repo). All `src/...` and `tests/...` paths below are relative to `ferrum/`. Work happens on the active chess-rl worktree branch; commits ride its existing PR.

**Conventions (all tasks):**
- Squares are `u8` 0–63, little-endian rank-file: `sq = rank*8 + file`, A1=0, B1=1, H8=63.
- Bitboards are plain `u64` (type alias `Bb`), bit `sq` set = occupied.
- Piece arrays are indexed `color*6 + piecetype` (piecetype: 0=P,1=N,2=B,3=R,4=Q,5=K).
- Scores are centipawns from the side-to-move's point of view. `MATE = 30_000`.
- Run tests with `cargo test --release` (perft in debug is painfully slow).
- Commit after every green step; messages `feat:`/`test:`/`chore:` style.

```rust
pub type Bb = u64;

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum Color { White, Black }

impl Color {
    pub fn flip(self) -> Color {
        match self { Color::White => Color::Black, Color::Black => Color::White }
    }
    pub fn idx(self) -> usize { self as usize }
}

pub const PAWN: usize = 0;
pub const KNIGHT: usize = 1;
pub const BISHOP: usize = 2;
pub const ROOK: usize = 3;
pub const QUEEN: usize = 4;
pub const KING: usize = 5;

/// Index into 12-element piece-bitboard arrays.
pub fn pc(c: Color, pt: usize) -> usize { c.idx() * 6 + pt }

pub fn bb(sq: u8) -> Bb { 1u64 << sq }
pub fn lsb(b: Bb) -> u8 { b.trailing_zeros() as u8 }
pub fn msb(b: Bb) -> u8 { 63 - b.leading_zeros() as u8 }
pub fn pop_lsb(b: &mut Bb) -> u8 { let s = lsb(*b); *b &= *b - 1; s }
pub fn file_of(sq: u8) -> u8 { sq & 7 }
pub fn rank_of(sq: u8) -> u8 { sq >> 3 }
pub fn sq(file: u8, rank: u8) -> u8 { rank * 8 + file }

pub fn sq_name(s: u8) -> String {
    format!("{}{}", (b'a' + file_of(s)) as char, rank_of(s) + 1)
}

pub fn parse_sq(s: &str) -> Option<u8> {
    let b = s.as_bytes();
    if b.len() != 2 { return None; }
    let f = b[0].wrapping_sub(b'a');
    let r = b[1].wrapping_sub(b'1');
    if f > 7 || r > 7 { return None; }
    Some(sq(f, r))
}
```

### Task 3: Attack tables (leapers + ray sliders)

**Files:**
- Create: `src/attacks.rs`
- Modify: `src/main.rs` (add `mod attacks;`)

Direction indices: `0=N, 1=S, 2=E, 3=W, 4=NE, 5=NW, 6=SE, 7=SW`. "Positive" directions (toward higher square index) are N, E, NE, NW; the rest are negative. Sliding attacks: take the full ray from the square; if it intersects occupancy, cut it at the first blocker (lsb of blockers for positive rays, msb for negative) by XORing away the blocker's own ray in the same direction. The blocker square itself stays attacked (captures).

```rust
use std::sync::OnceLock;
use crate::types::*;

struct Tables {
    knight: [Bb; 64],
    king: [Bb; 64],
    pawn: [[Bb; 64]; 2], // [color][sq]
    rays: [[Bb; 64]; 8], // [dir][sq]
}

static TABLES: OnceLock<Tables> = OnceLock::new();

// (df, dr) per direction index; positive = attacked squares have higher index
const DIRS: [(i8, i8); 8] = [
    (0, 1), (0, -1), (1, 0), (-1, 0),   // N S E W
    (1, 1), (-1, 1), (1, -1), (-1, -1), // NE NW SE SW
];
const POSITIVE: [bool; 8] = [true, false, true, false, true, true, false, false];

fn on_board(f: i8, r: i8) -> bool { (0..8).contains(&f) && (0..8).contains(&r) }

fn build() -> Tables {
    let mut t = Tables {
        knight: [0; 64], king: [0; 64], pawn: [[0; 64]; 2], rays: [[0; 64]; 8],
    };
    for s in 0u8..64 {
        let (f, r) = (file_of(s) as i8, rank_of(s) as i8);
        for (df, dr) in [(1, 2), (2, 1), (2, -1), (1, -2), (-1, -2), (-2, -1), (-2, 1), (-1, 2)] {
            if on_board(f + df, r + dr) { t.knight[s as usize] |= bb(sq((f + df) as u8, (r + dr) as u8)); }
        }
        for (df, dr) in DIRS {
            if on_board(f + df, r + dr) { t.king[s as usize] |= bb(sq((f + df) as u8, (r + dr) as u8)); }
        }
        for (c, dr) in [(0usize, 1i8), (1usize, -1i8)] {
            for df in [-1i8, 1] {
                if on_board(f + df, r + dr) { t.pawn[c][s as usize] |= bb(sq((f + df) as u8, (r + dr) as u8)); }
            }
        }
        for (d, (df, dr)) in DIRS.iter().enumerate() {
            let (mut cf, mut cr) = (f + df, r + dr);
            while on_board(cf, cr) {
                t.rays[d][s as usize] |= bb(sq(cf as u8, cr as u8));
                cf += df; cr += dr;
            }
        }
    }
    t
}

fn tables() -> &'static Tables { TABLES.get_or_init(build) }

pub fn knight_attacks(s: u8) -> Bb { tables().knight[s as usize] }
pub fn king_attacks(s: u8) -> Bb { tables().king[s as usize] }
pub fn pawn_attacks(c: Color, s: u8) -> Bb { tables().pawn[c.idx()][s as usize] }

fn ray_attack(dir: usize, s: u8, occ: Bb) -> Bb {
    let t = tables();
    let ray = t.rays[dir][s as usize];
    let blockers = ray & occ;
    if blockers == 0 { return ray; }
    let blocker = if POSITIVE[dir] { lsb(blockers) } else { msb(blockers) };
    ray ^ t.rays[dir][blocker as usize]
}

pub fn rook_attacks(s: u8, occ: Bb) -> Bb {
    ray_attack(0, s, occ) | ray_attack(1, s, occ) | ray_attack(2, s, occ) | ray_attack(3, s, occ)
}
pub fn bishop_attacks(s: u8, occ: Bb) -> Bb {
    ray_attack(4, s, occ) | ray_attack(5, s, occ) | ray_attack(6, s, occ) | ray_attack(7, s, occ)
}
pub fn queen_attacks(s: u8, occ: Bb) -> Bb { rook_attacks(s, occ) | bishop_attacks(s, occ) }
```

```rust
use std::sync::OnceLock;

pub struct Zobrist {
    pub piece: [[u64; 64]; 12],
    pub side: u64,
    pub castling: [u64; 16],
    pub ep_file: [u64; 8],
}

static Z: OnceLock<Zobrist> = OnceLock::new();

fn splitmix(state: &mut u64) -> u64 {
    *state = state.wrapping_add(0x9E37_79B9_7F4A_7C15);
    let mut z = *state;
    z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
    z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
    z ^ (z >> 31)
}

pub fn z() -> &'static Zobrist {
    Z.get_or_init(|| {
        let mut s = 0x00C0_FFEE_u64;
        let mut zb = Zobrist {
            piece: [[0; 64]; 12], side: 0, castling: [0; 16], ep_file: [0; 8],
        };
        for p in 0..12 { for q in 0..64 { zb.piece[p][q] = splitmix(&mut s); } }
        zb.side = splitmix(&mut s);
        for c in 0..16 { zb.castling[c] = splitmix(&mut s); }
        for f in 0..8 { zb.ep_file[f] = splitmix(&mut s); }
        zb
    })
}
```

```rust
use crate::attacks::*;
use crate::types::*;
use crate::zobrist::z;

#[derive(Clone)]
pub struct Board {
    pub bb: [Bb; 12],
    pub occ: [Bb; 2],
    pub side: Color,
    pub castling: u8, // WK=1 WQ=2 BK=4 BQ=8
    pub ep: Option<u8>,
    pub halfmove: u16,
    pub fullmove: u16,
    pub hash: u64,
}

impl Board {
    pub fn all(&self) -> Bb { self.occ[0] | self.occ[1] }

    pub fn piece_on(&self, s: u8) -> Option<usize> {
        (0..12).find(|&p| self.bb[p] & bb(s) != 0)
    }

    pub fn king_sq(&self, c: Color) -> u8 { lsb(self.bb[pc(c, KING)]) }

    /// Is square `s` attacked by color `c`?
    pub fn attacked(&self, s: u8, c: Color) -> bool {
        // pawn_attacks(c.flip(), s) = squares from which a c-pawn attacks s
        if pawn_attacks(c.flip(), s) & self.bb[pc(c, PAWN)] != 0 { return true; }
        if knight_attacks(s) & self.bb[pc(c, KNIGHT)] != 0 { return true; }
        if king_attacks(s) & self.bb[pc(c, KING)] != 0 { return true; }
        let occ = self.all();
        if bishop_attacks(s, occ) & (self.bb[pc(c, BISHOP)] | self.bb[pc(c, QUEEN)]) != 0 { return true; }
        if rook_attacks(s, occ) & (self.bb[pc(c, ROOK)] | self.bb[pc(c, QUEEN)]) != 0 { return true; }
        false
    }

    pub fn in_check(&self, c: Color) -> bool { self.attacked(self.king_sq(c), c.flip()) }

    fn compute_hash(&self) -> u64 {
        let zb = z();
        let mut h = 0u64;
        for p in 0..12 {
            let mut b = self.bb[p];
            while b != 0 { h ^= zb.piece[p][pop_lsb(&mut b) as usize]; }
        }
        if self.side == Color::Black { h ^= zb.side; }
        h ^= zb.castling[self.castling as usize];
        if let Some(e) = self.ep { h ^= zb.ep_file[file_of(e) as usize]; }
        h
    }

    pub fn from_fen(fen: &str) -> Result<Board, String> {
        let parts: Vec<&str> = fen.split_whitespace().collect();
        if parts.len() < 4 { return Err("bad fen".into()); }
        let mut b = Board {
            bb: [0; 12], occ: [0; 2], side: Color::White, castling: 0,
            ep: None, halfmove: 0, fullmove: 1, hash: 0,
        };
        let (mut f, mut r) = (0u8, 7u8);
        for ch in parts[0].chars() {
            match ch {
                '/' => { f = 0; r -= 1; }
                '1'..='8' => f += ch as u8 - b'0',
                _ => {
                    let c = if ch.is_uppercase() { Color::White } else { Color::Black };
                    let pt = match ch.to_ascii_lowercase() {
                        'p' => PAWN, 'n' => KNIGHT, 'b' => BISHOP,
                        'r' => ROOK, 'q' => QUEEN, 'k' => KING,
                        _ => return Err(format!("bad piece {ch}")),
                    };
                    let s = sq(f, r);
                    b.bb[pc(c, pt)] |= bb(s);
                    b.occ[c.idx()] |= bb(s);
                    f += 1;
                }
            }
        }
        b.side = if parts[1] == "w" { Color::White } else { Color::Black };
        for ch in parts[2].chars() {
            b.castling |= match ch { 'K' => 1, 'Q' => 2, 'k' => 4, 'q' => 8, _ => 0 };
        }
        if parts[3] != "-" { b.ep = parse_sq(parts[3]); }
        if parts.len() > 4 { b.halfmove = parts[4].parse().unwrap_or(0); }
        if parts.len() > 5 { b.fullmove = parts[5].parse().unwrap_or(1); }
        b.hash = b.compute_hash();
        Ok(b)
    }

    pub fn startpos() -> Board {
        Board::from_fen("rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1").unwrap()
    }

    pub fn to_fen(&self) -> String {
        let mut s = String::new();
        for r in (0..8).rev() {
            let mut empty = 0;
            for f in 0..8 {
                match self.piece_on(sq(f, r)) {
                    None => empty += 1,
                    Some(p) => {
                        if empty > 0 { s.push((b'0' + empty) as char); empty = 0; }
                        s.push(b"PNBRQKpnbrqk"[p] as char);
                    }
                }
            }
            if empty > 0 { s.push((b'0' + empty) as char); }
            if r > 0 { s.push('/'); }
        }
        s.push(if self.side == Color::White { ' ' } else { ' ' });
        s.push_str(if self.side == Color::White { "w" } else { "b" });
        s.push(' ');
        if self.castling == 0 { s.push('-'); } else {
            for (bit, ch) in [(1, 'K'), (2, 'Q'), (4, 'k'), (8, 'q')] {
                if self.castling & bit != 0 { s.push(ch); }
            }
        }
        s.push(' ');
        match self.ep { Some(e) => s.push_str(&sq_name(e)), None => s.push('-') }
        s.push_str(&format!(" {} {}", self.halfmove, self.fullmove));
        s
    }
}
```

```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Move(pub u16);

pub const FLAG_QUIET: u16 = 0;
pub const FLAG_DPP: u16 = 1;
pub const FLAG_OO: u16 = 2;
pub const FLAG_OOO: u16 = 3;
pub const FLAG_CAP: u16 = 4;
pub const FLAG_EP: u16 = 5;
pub const FLAG_PROMO: u16 = 8; // 8..=11 quiet promo N/B/R/Q; 12..=15 capture promo

impl Move {
    pub const NONE: Move = Move(0);
    pub fn new(from: u8, to: u8, flags: u16) -> Move {
        Move((from as u16) | ((to as u16) << 6) | (flags << 12))
    }
    pub fn from(self) -> u8 { (self.0 & 63) as u8 }
    pub fn to(self) -> u8 { ((self.0 >> 6) & 63) as u8 }
    pub fn flags(self) -> u16 { self.0 >> 12 }

        let mut s = format!("{}{}", sq_name(self.from()), sq_name(self.to()));
        if self.is_promo() { s.push(b"nbrq"[(self.flags() & 3) as usize] as char); }

    }
```

```rust
use crate::attacks::*;
use crate::board::Board;
use crate::moves::*;
use crate::types::*;

pub fn generate(b: &Board, list: &mut Vec<Move>) {
    let us = b.side;
    let them = us.flip();
    let own = b.occ[us.idx()];
    let opp = b.occ[them.idx()];
    let all = own | opp;

    // --- pawns ---
    let pawns = b.bb[pc(us, PAWN)];
    let (push, promo_rank, dpp_rank): (i8, u8, u8) =
        if us == Color::White { (8, 7, 3) } else { (-8, 0, 4) };
    let mut p = pawns;
    while p != 0 {
        let from = pop_lsb(&mut p);
        let to1 = (from as i8 + push) as u8;
        if all & bb(to1) == 0 {
            if rank_of(to1) == promo_rank {
                for n in 0..4 { list.push(Move::new(from, to1, FLAG_PROMO + n)); }
            } else {
                list.push(Move::new(from, to1, FLAG_QUIET));
                let start_rank = if us == Color::White { 1 } else { 6 };
                if rank_of(from) == start_rank {
                    let to2 = (from as i8 + 2 * push) as u8;
                    if all & bb(to2) == 0 {
                        debug_assert_eq!(rank_of(to2), dpp_rank);
                        list.push(Move::new(from, to2, FLAG_DPP));
                    }
                }
            }
        }
        let mut caps = pawn_attacks(us, from) & opp;
        while caps != 0 {
            let to = pop_lsb(&mut caps);
            if rank_of(to) == promo_rank {
                for n in 0..4 { list.push(Move::new(from, to, FLAG_PROMO + FLAG_CAP + n)); }
            } else {
                list.push(Move::new(from, to, FLAG_CAP));
            }
        }
        if let Some(ep) = b.ep {
            if pawn_attacks(us, from) & bb(ep) != 0 {
                list.push(Move::new(from, ep, FLAG_EP));
            }
        }
    }

    // --- knights, bishops, rooks, queens, king ---
    for (pt, att) in [
        (KNIGHT, knight_attacks as fn(u8) -> Bb),
        (KING, king_attacks as fn(u8) -> Bb),
    ] {
        let mut pieces = b.bb[pc(us, pt)];
        while pieces != 0 {
            let from = pop_lsb(&mut pieces);
            push_targets(list, from, att(from) & !own, opp);
        }
    }
    for pt in [BISHOP, ROOK, QUEEN] {
        let mut pieces = b.bb[pc(us, pt)];
        while pieces != 0 {
            let from = pop_lsb(&mut pieces);
            let a = match pt {
                BISHOP => bishop_attacks(from, all),
                ROOK => rook_attacks(from, all),
                _ => queen_attacks(from, all),
            };
            push_targets(list, from, a & !own, opp);
        }
    }

    // --- castling (fully legal when emitted) ---
    let (ks_bit, qs_bit, king_from) = if us == Color::White { (1u8, 2u8, 4u8) } else { (4u8, 8u8, 60u8) };
    if b.bb[pc(us, KING)] & bb(king_from) != 0 && !b.in_check(us) {
        // king side: f/g empty, e/f/g not attacked
        if b.castling & ks_bit != 0
            && all & (bb(king_from + 1) | bb(king_from + 2)) == 0
            && !b.attacked(king_from + 1, them) && !b.attacked(king_from + 2, them)
        {
            list.push(Move::new(king_from, king_from + 2, FLAG_OO));
        }
        // queen side: b/c/d empty, e/d/c not attacked
        if b.castling & qs_bit != 0
            && all & (bb(king_from - 1) | bb(king_from - 2) | bb(king_from - 3)) == 0
            && !b.attacked(king_from - 1, them) && !b.attacked(king_from - 2, them)
        {
            list.push(Move::new(king_from, king_from - 2, FLAG_OOO));
        }
    }
}

fn push_targets(list: &mut Vec<Move>, from: u8, mut targets: Bb, opp: Bb) {
    while targets != 0 {
        let to = pop_lsb(&mut targets);
        let fl = if opp & bb(to) != 0 { FLAG_CAP } else { FLAG_QUIET };
        list.push(Move::new(from, to, fl));
    }
}
```

```rust
/// Which castling rights survive a move touching this square.
/// Rights bits: WK=1 WQ=2 BK=4 BQ=8. a1=WQ rook, h1=WK rook, e1=W king, mirrored for black.
const CASTLE_MASK: [u8; 64] = {
    let mut m = [15u8; 64];
    m[0] = 15 - 2;   // a1
    m[7] = 15 - 1;   // h1
    m[4] = 15 - 3;   // e1
    m[56] = 15 - 8;  // a8
    m[63] = 15 - 4;  // h8
    m[60] = 15 - 12; // e8
    m
};

pub struct Undo {
    captured: Option<usize>,
    castling: u8,
    ep: Option<u8>,
    halfmove: u16,
    hash: u64,
}

impl Board {
    fn move_piece(&mut self, p: usize, from: u8, to: u8) {
        let zb = crate::zobrist::z();
        self.bb[p] ^= bb(from) | bb(to);
        self.occ[p / 6] ^= bb(from) | bb(to);
        self.hash ^= zb.piece[p][from as usize] ^ zb.piece[p][to as usize];
    }
    fn toggle_piece(&mut self, p: usize, s: u8) {
        self.bb[p] ^= bb(s);
        self.occ[p / 6] ^= bb(s);
        self.hash ^= crate::zobrist::z().piece[p][s as usize];
    }

    pub fn make(&mut self, m: crate::moves::Move) -> Undo {
        use crate::moves::*;
        let zb = crate::zobrist::z();
        let us = self.side;
        let mut undo = Undo {
            captured: None, castling: self.castling, ep: self.ep,
            halfmove: self.halfmove, hash: self.hash,
        };
        let (from, to, flags) = (m.from(), m.to(), m.flags());
        let piece = self.piece_on(from).expect("no piece on from-square");

        // clear old ep from hash; new ep set below if DPP
        if let Some(e) = self.ep { self.hash ^= zb.ep_file[file_of(e) as usize]; }
        self.ep = None;
        self.halfmove += 1;
        if piece % 6 == PAWN { self.halfmove = 0; }

        if m.is_capture() {
            let cap_sq = if flags == FLAG_EP {
                if us == Color::White { to - 8 } else { to + 8 }
            } else { to };
            let cap = self.piece_on(cap_sq).expect("no captured piece");
            self.toggle_piece(cap, cap_sq);
            undo.captured = Some(cap);
            self.halfmove = 0;
        }

        self.move_piece(piece, from, to);

        if m.is_promo() {
            self.toggle_piece(piece, to);                       // remove pawn
            self.toggle_piece(pc(us, m.promo_pt()), to);        // drop promo piece
        } else if flags == FLAG_OO {
            let (rf, rt) = if us == Color::White { (7, 5) } else { (63, 61) };
            self.move_piece(pc(us, ROOK), rf, rt);
        } else if flags == FLAG_OOO {
            let (rf, rt) = if us == Color::White { (0, 3) } else { (56, 59) };
            self.move_piece(pc(us, ROOK), rf, rt);
        } else if flags == FLAG_DPP {
            let ep = if us == Color::White { from + 8 } else { from - 8 };
            self.ep = Some(ep);
            self.hash ^= zb.ep_file[file_of(ep) as usize];
        }

        self.hash ^= zb.castling[self.castling as usize];
        self.castling &= CASTLE_MASK[from as usize] & CASTLE_MASK[to as usize];
        self.hash ^= zb.castling[self.castling as usize];

        if us == Color::Black { self.fullmove += 1; }
        self.side = us.flip();
        self.hash ^= zb.side;
        undo
    }

    pub fn unmake(&mut self, m: crate::moves::Move, u: Undo) {
        use crate::moves::*;
        let us = self.side.flip(); // the side that made the move
        let (from, to, flags) = (m.from(), m.to(), m.flags());

        if m.is_promo() {
            self.toggle_piece(pc(us, m.promo_pt()), to);
            self.toggle_piece(pc(us, PAWN), to);
        }
        let piece = self.piece_on(to).expect("no piece on to-square");
        self.move_piece(piece, to, from);

        if flags == FLAG_OO {
            let (rf, rt) = if us == Color::White { (7, 5) } else { (63, 61) };
            self.move_piece(pc(us, ROOK), rt, rf);
        } else if flags == FLAG_OOO {
            let (rf, rt) = if us == Color::White { (0, 3) } else { (56, 59) };
            self.move_piece(pc(us, ROOK), rt, rf);
        }
        if let Some(cap) = u.captured {
            let cap_sq = if flags == FLAG_EP {
                if us == Color::White { to - 8 } else { to + 8 }
            } else { to };
            self.toggle_piece(cap, cap_sq);
        }
        if us == Color::Black { self.fullmove -= 1; }
        self.side = us;
        self.castling = u.castling;
        self.ep = u.ep;
        self.halfmove = u.halfmove;
        self.hash = u.hash; // full restore — no incremental unmake hashing needed
    }
}
```

```rust
use crate::board::Board;
use crate::movegen::generate;

pub fn perft(b: &mut Board, depth: u32) -> u64 {
    if depth == 0 { return 1; }
    let mut moves = Vec::with_capacity(64);
    generate(b, &mut moves);
    let mut nodes = 0;
    for m in moves {
        let u = b.make(m);
        if !b.in_check(b.side.flip()) {
            nodes += if depth == 1 { 1 } else { perft(b, depth - 1) };
        }
        b.unmake(m, u);
    }
    nodes
}

/// Per-root-move breakdown, for debugging count mismatches.
pub fn perft_divide(b: &mut Board, depth: u32) {
    let mut moves = Vec::new();
    generate(b, &mut moves);
    let mut total = 0;
    for m in moves {
        let u = b.make(m);
        if !b.in_check(b.side.flip()) {
            let n = if depth <= 1 { 1 } else { perft(b, depth - 1) };
            println!("{}: {}", m.uci(), n);
            total += n;
        }
        b.unmake(m, u);
    }
    println!("total: {total}");
}
```

```rust
        let mut score = 0i32; // from white's POV
        for pt in 0..6 {
            let mut w = b.bb[pc(Color::White, pt)];
            while w != 0 {
                let s = pop_lsb(&mut w) as usize;
                score += MATERIAL[pt] + PST[pt][s ^ 56];
            }
            let mut bl = b.bb[pc(Color::Black, pt)];
            while bl != 0 {
                let s = pop_lsb(&mut bl) as usize;
                score -= MATERIAL[pt] + PST[pt][s];
            }
        }
        if b.side == Color::White { score } else { -score }
    }
}
```

```rust
use crate::moves::Move;

pub const BOUND_EXACT: u8 = 1;
pub const BOUND_LOWER: u8 = 2;
pub const BOUND_UPPER: u8 = 3;

#[derive(Clone, Copy)]
pub struct Entry {
    pub key: u64,
    pub mv: Move,
    pub score: i32,
    pub depth: i8,
    pub bound: u8,
}

pub struct Tt {
    entries: Vec<Entry>,
    mask: usize,
}

impl Tt {
    /// `mb` megabytes, rounded down to a power-of-two entry count.
    pub fn new(mb: usize) -> Tt {
        let bytes = mb.max(1) * 1024 * 1024;
        let n = (bytes / std::mem::size_of::<Entry>()).next_power_of_two() / 2;
        Tt {
            entries: vec![Entry { key: 0, mv: Move::NONE, score: 0, depth: -1, bound: 0 }; n],
            mask: n - 1,
        }
    }
    pub fn len(&self) -> usize { self.entries.len() }
    pub fn clear(&mut self) {
        for e in &mut self.entries { *e = Entry { key: 0, mv: Move::NONE, score: 0, depth: -1, bound: 0 }; }
    }
    pub fn probe(&self, key: u64) -> Option<Entry> {
        let e = self.entries[key as usize & self.mask];
        if e.bound != 0 && e.key == key { Some(e) } else { None }
    }
    pub fn store(&mut self, key: u64, mv: Move, score: i32, depth: i8, bound: u8) {
        self.entries[key as usize & self.mask] = Entry { key, mv, score, depth, bound };
    }
}
```

```rust
use crate::board::Board;
use crate::eval::{Eval, Hce, MATERIAL};
use crate::movegen::generate;
use crate::moves::*;
use crate::tt::*;
use crate::types::*;
use std::time::Instant;

pub const MATE: i32 = 30_000;
const MATE_BOUND: i32 = MATE - 1_000; // scores beyond this are mate scores

#[derive(Default)]
pub struct Limits {
    pub depth: Option<u32>,
    pub movetime: Option<u64>, // ms
    pub wtime: Option<u64>,
    pub btime: Option<u64>,
    pub winc: Option<u64>,
    pub binc: Option<u64>,
}

pub struct Searcher {
    pub tt: Tt,
    nodes: u64,
    deadline: Option<Instant>,
    stopped: bool,
    history: Vec<u64>, // zobrist hashes: game history + current search line
    eval: Hce,
}

impl Searcher {
    pub fn new(tt_mb: usize) -> Searcher {
        Searcher { tt: Tt::new(tt_mb), nodes: 0, deadline: None, stopped: false, history: Vec::new(), eval: Hce }
    }

    /// game_history: zobrist hashes of all prior game positions (for repetition).
    pub fn think(&mut self, b: &mut Board, limits: &Limits, game_history: &[u64]) -> Move {
        self.nodes = 0;
        self.stopped = false;
        self.history = game_history.to_vec();
        self.deadline = compute_deadline(b, limits);
        let max_depth = limits.depth.unwrap_or(64);

        let mut best = Move::NONE;
        for depth in 1..=max_depth {
            let score = self.negamax(b, depth as i32, -MATE, MATE, 0);
            if self.stopped { break; }
            if let Some(e) = self.tt.probe(b.hash) { best = e.mv; }
            println!(
                "info depth {} score {} nodes {} pv {}",
                depth, fmt_score(score), self.nodes,
                if best == Move::NONE { "(none)".into() } else { best.uci() }
            );
            if best == Move::NONE { break; }        // mated/stalemated at root
            if score.abs() > MATE_BOUND { break; }  // proven mate: stop deepening
        }
        best
    }

    fn out_of_time(&mut self) -> bool {
        if self.nodes % 2048 == 0 {
            if let Some(d) = self.deadline {
                if Instant::now() >= d { self.stopped = true; }
            }
        }
        self.stopped
    }

    fn is_repetition(&self, hash: u64) -> bool {
        self.history.iter().rev().skip(1).step_by(2).any(|&h| h == hash)
    }

    fn negamax(&mut self, b: &mut Board, depth: i32, mut alpha: i32, beta: i32, ply: i32) -> i32 {
        self.nodes += 1;
        if self.out_of_time() { return 0; }
        if ply > 0 && (b.halfmove >= 100 || self.is_repetition(b.hash)) { return 0; }
        if depth <= 0 { return self.qsearch(b, alpha, beta); }

        let mut tt_move = Move::NONE;
        if let Some(e) = self.tt.probe(b.hash) {
            tt_move = e.mv;
            if ply > 0 && e.depth as i32 >= depth {
                let s = score_from_tt(e.score, ply);
                match e.bound {
                    BOUND_EXACT => return s,
                    BOUND_LOWER if s >= beta => return s,
                    BOUND_UPPER if s <= alpha => return s,
                    _ => {}
                }
            }
        }

        let mut moves = Vec::with_capacity(64);
        generate(b, &mut moves);
        order_moves(b, &mut moves, tt_move);

        let mut legal = 0;
        let mut best_score = -MATE - 1;
        let mut best_move = Move::NONE;
        let mut bound = BOUND_UPPER;

        for m in moves {
            let u = b.make(m);
            if b.in_check(b.side.flip()) { b.unmake(m, u); continue; }
            legal += 1;
            self.history.push(b.hash);
            let score = -self.negamax(b, depth - 1, -beta, -alpha, ply + 1);
            self.history.pop();
            b.unmake(m, u);
            if self.stopped { return 0; }

            if score > best_score {
                best_score = score;
                best_move = m;
                if score > alpha {
                    alpha = score;
                    bound = BOUND_EXACT;
                    if alpha >= beta { bound = BOUND_LOWER; break; }
                }
            }
        }

        if legal == 0 {
            return if b.in_check(b.side) { -MATE + ply } else { 0 };
        }
        self.tt.store(b.hash, best_move, score_to_tt(best_score, ply), depth as i8, bound);
        best_score
    }

    fn qsearch(&mut self, b: &mut Board, mut alpha: i32, beta: i32) -> i32 {
        self.nodes += 1;
        if self.out_of_time() { return 0; }
        let stand = self.eval.eval(b);
        if stand >= beta { return stand; }
        if stand > alpha { alpha = stand; }

        let mut moves = Vec::with_capacity(32);
        generate(b, &mut moves);
        moves.retain(|m| m.is_capture() || m.is_promo());
        order_moves(b, &mut moves, Move::NONE);

        let mut best = stand;
        for m in moves {
            let u = b.make(m);
            if b.in_check(b.side.flip()) { b.unmake(m, u); continue; }
            let score = -self.qsearch(b, -beta, -alpha);
            b.unmake(m, u);
            if self.stopped { return 0; }
            if score > best { best = score; }
            if score > alpha { alpha = score; }
            if alpha >= beta { break; }
        }
        best
    }
}

/// MVV-LVA: most valuable victim, least valuable attacker. TT move first.
fn order_moves(b: &Board, moves: &mut [Move], tt_move: Move) {
    let key = |m: &Move| -> i32 {
        if *m == tt_move { return 1_000_000; }
        if m.is_capture() {
            let victim = b.piece_on(m.to()).map(|p| MATERIAL[p % 6]).unwrap_or(100); // ep: pawn
            let attacker = b.piece_on(m.from()).map(|p| MATERIAL[p % 6]).unwrap_or(0);
            return 10_000 + victim * 10 - attacker;
        }
        if m.is_promo() { return 9_000; }
        0
    };
    moves.sort_by_key(|m| -key(m));
}

fn score_to_tt(s: i32, ply: i32) -> i32 {
    if s > MATE_BOUND { s + ply } else if s < -MATE_BOUND { s - ply } else { s }
}
fn score_from_tt(s: i32, ply: i32) -> i32 {
    if s > MATE_BOUND { s - ply } else if s < -MATE_BOUND { s + ply } else { s }
}

fn fmt_score(s: i32) -> String {
    if s.abs() > MATE_BOUND {
        let plies = MATE - s.abs();
        let mate_in = (plies + 1) / 2;
        format!("mate {}", if s > 0 { mate_in } else { -mate_in })
    } else {
        format!("cp {s}")
    }
}

fn compute_deadline(b: &Board, limits: &Limits) -> Option<Instant> {
    if let Some(mt) = limits.movetime {
        return Some(Instant::now() + std::time::Duration::from_millis(mt.saturating_sub(20)));
    }
    let (time, inc) = if b.side == Color::White { (limits.wtime, limits.winc) } else { (limits.btime, limits.binc) };
    let time = time?;
    let inc = inc.unwrap_or(0);
    // M0 heuristic: 1/25th of remaining + half the increment (real time mgmt is an M1 SPRT patch)
    let alloc = (time / 25 + inc / 2).max(10).min(time.saturating_sub(50).max(10));
    Some(Instant::now() + std::time::Duration::from_millis(alloc))
}
```

```rust
                    if let Ok(mb) = v.parse::<usize>() { searcher = Searcher::new(mb); }
                }
            }
            Some("ucinewgame") => {
                searcher.tt.clear();
                board = Board::startpos();
                history.clear();
            }
            Some("position") => {

                    i += 1;

                        .take_while(|&&t| t != "moves").copied().collect();

                    i += 1 + fen.len();

                        }
                    }
                }

    let mut b2 = b.clone();

        if m.uci() != uci { return false; }
        let u = b2.make(m);
        let legal = !b2.in_check(b2.side.flip());
        b2.unmake(m, u);
        legal
    })
}
```
