# ferrum M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take ferrum from ~1930 (M0) to ~2300–2500 anchored strength by adding the community-canonical search features (each SPRT-lite-gated), magic bitboards, and real time management, and by standing up a reusable CCRL-anchored gauntlet.

**Architecture:** A Rust `std`-only crate at `ferrum/` (unchanged module layout from M0). M1 rewrites `attacks.rs` sliders to magic bitboards, grows `search.rs` from plain alpha-beta into a full PVS search with pruning/ordering/extensions, adds two null-move helpers to `board.rs`, and adds three shell/python tools plus an anchor-pool doc. Every functional patch is gated by a fastchess SPRT-lite run comparing the working-tree binary against the pre-patch binary; only proven-positive patches are committed.

**Tech Stack:** Rust (stable, `std` only), fastchess (match runner + SPRT), Ordo (rating), python-chess (opening book), bash.

**Design spec:** `docs/superpowers/specs/2026-07-15-ferrum-m1-search-design.md`.

## Conventions used by every task

**Paths** are relative to the repo root (`ferrum/` is the crate). Run cargo from `ferrum/`.

**Green-check** (run after every code change, must all pass):
```bash
cd ferrum
cargo test --release
cargo clippy --all-targets --release -- -D warnings
cargo run --release -- bench    # prints "bench: N nodes M nps" — record N in the ledger
```

**The per-patch SPRT pipeline** (Tasks 4–16 — every *functional* engine change):
1. On the clean pre-patch HEAD: `cd ferrum && cargo build --release && cp target/release/ferrum /tmp/ferrum-base`
2. Implement the patch (TDD steps below).
3. Green-check (above).
4. `ferrum/tools/sprt.sh /tmp/ferrum-base` — runs the SPRT-lite A/B.
5. **SPRT accepts H1** (candidate stronger, or Elo clearly positive at the 2000-game cap) → commit + add a ledger row. **SPRT accepts H0** (no gain) → `git checkout -- .` to revert, add a ledger row recording the measured Elo, and move on.

SPRT-lite settings live in `sprt.sh`: STC 8+0.08, bounds `elo0=0 elo1=8`, α=β=0.05, ≤2000 games, concurrency 4. A patch that is a *pure* refactor with identical node counts (none in M1) would skip SPRT; every M1 patch changes search behaviour, so all run it.

```bash
#!/usr/bin/env bash
# SPRT-lite A/B test for a ferrum search patch.
#
#   tools/sprt.sh <baseline_bin> [candidate_bin]
#
# baseline_bin: a ferrum binary saved from the pre-patch HEAD, e.g.
#   cd ferrum && cargo build --release && cp target/release/ferrum /tmp/ferrum-base
# candidate_bin: defaults to a fresh working-tree release build.
#
# Env overrides: FASTCHESS, BOOK, TC, ROUNDS, CONCURRENCY, ELO0, ELO1.
# (No Stockfish: the SPRT is ferrum self-play. Stockfish is not used anywhere in M1.)
set -euo pipefail

BASE="${1:?usage: sprt.sh <baseline_bin> [candidate_bin]}"
FERRUM_DIR="$(cd "$(dirname "$0")/.." && pwd)"
FASTCHESS="${FASTCHESS:-/Users/james/Documents/GitHub/fastchess/fastchess}"
BOOK="${BOOK:-$FERRUM_DIR/books/openings_m1.epd}"
TC="${TC:-8+0.08}"
ROUNDS="${ROUNDS:-1000}"          # up to 2*ROUNDS games (paired, -repeat)
CONCURRENCY="${CONCURRENCY:-4}"
ELO0="${ELO0:-0}"; ELO1="${ELO1:-8}"

if [ -n "${2:-}" ]; then
  CAND="$2"
else
  ( cd "$FERRUM_DIR" && cargo build --release )
  CAND="$FERRUM_DIR/target/release/ferrum"
fi

[ -x "$BASE" ] || { echo "baseline not executable: $BASE" >&2; exit 1; }
[ -x "$CAND" ] || { echo "candidate not executable: $CAND" >&2; exit 1; }
[ -f "$BOOK" ] || { echo "opening book missing: $BOOK (run Task 2)" >&2; exit 1; }

PGN="$(mktemp -t ferrum-sprt-XXXXXX.pgn)"
echo "candidate: $CAND"
echo "baseline:  $BASE"
echo "book:      $BOOK   tc: $TC   sprt: [$ELO0,$ELO1]   cap: $((ROUNDS*2)) games"

"$FASTCHESS" \
  -engine cmd="$CAND" name=cand \
  -engine cmd="$BASE" name=base \
  -each tc="$TC" \
  -openings file="$BOOK" format=epd order=random \
  -rounds "$ROUNDS" -games 2 -repeat \
  -concurrency "$CONCURRENCY" \
  -sprt elo0="$ELO0" elo1="$ELO1" alpha=0.05 beta=0.05 \
  -pgnout file="$PGN"

echo "pgn: $PGN"
```

```python
def _expand(board: chess.Board, plies_left: int, seen: set, out: list, max_per_seed: int):
    """Depth-first walk emitting EPDs, at most `max_per_seed` per seed line."""
    if len(out) and out.count(out[-1]):  # cheap guard; real dedupe via `seen`
        pass
    epd = board.epd()
    if epd not in seen:
        seen.add(epd)
        out.append(epd)
    if plies_left == 0 or len(out) >= max_per_seed:
        return
    # branch on a handful of reasonable legal moves (keep the tree small + sane)
    legal = list(board.legal_moves)
    for mv in legal[: min(3, len(legal))]:
        board.push(mv)
        _expand(board, plies_left - 1, seen, out, max_per_seed)
        board.pop()


def main() -> int:
    seen: set = set()
    all_epds: list = []
    for line in OPENINGS:
        board = chess.Board()
        for san in line.split():
            board.push_san(san)
        per_seed: list = []
        _expand(board, 2, seen, per_seed, max_per_seed=40)
        all_epds.extend(per_seed)
    for epd in all_epds:
        print(epd)
    print(f"generated {len(all_epds)} opening positions", file=sys.stderr)
    return 0
```

(c) Magic infrastructure:
```rust
struct Magic { mask: Bb, magic: u64, shift: u32, offset: usize }
struct Magics { table: Vec<Bb>, rook: [Magic; 64], bishop: [Magic; 64] }
static MAGICS: OnceLock<Magics> = OnceLock::new();

fn edges(s: u8) -> Bb {
    let (f, r) = (file_of(s), rank_of(s));
    let file_ab = 0x0101_0101_0101_0101u64;
    let rank_18 = 0x0000_0000_0000_00FFu64;
    ((file_ab | file_ab << 7) & !(file_ab << f))
        | ((rank_18 | rank_18 << 56) & !(rank_18 << (8 * r)))
}
// occupancy mask for a slider on `s` = reference attacks on an empty board, minus board edges
fn slider_mask(s: u8, rook: bool) -> Bb {
    let full = if rook { rook_ref(s, 0) } else { bishop_ref(s, 0) };
    full & !edges(s)
}
// enumerate the i-th subset of `mask` (carry-rippler)
fn subset(mask: Bb, mut i: u32) -> Bb {
    let mut occ = 0u64; let mut m = mask;
    while m != 0 {
        let bit = m & m.wrapping_neg();
        if i & 1 != 0 { occ |= bit; }
        i >>= 1; m &= m - 1;
    }
    occ
}
fn build_magics() -> Magics {
    let mut table: Vec<Bb> = Vec::new();
    let mut seed = 0x00C0_FFEE_D00D_1234u64;
    let mut rng = || splitmix64(&mut seed) & splitmix64(&mut seed) & splitmix64(&mut seed);
    let mk = |rook: bool, table: &mut Vec<Bb>, rng: &mut dyn FnMut() -> u64| -> [Magic; 64] {
        core::array::from_fn(|si| {
            let s = si as u8;
            let mask = slider_mask(s, rook);
            let bits = mask.count_ones();
            let n = 1usize << bits;
            let mut occs = vec![0u64; n];
            let mut atts = vec![0u64; n];
            for i in 0..n as u32 {
                occs[i as usize] = subset(mask, i);
                atts[i as usize] = if rook { rook_ref(s, occs[i as usize]) } else { bishop_ref(s, occs[i as usize]) };
            }
            let offset = table.len();
            table.resize(offset + n, 0);
            let shift = 64 - bits;
            loop {
                let magic = rng();
                if (mask.wrapping_mul(magic) >> 56).count_ones() < 6 { continue; } // heuristic
                let mut used = vec![u64::MAX; n];
                let mut ok = true;
                for i in 0..n {
                    let idx = ((occs[i].wrapping_mul(magic)) >> shift) as usize;
                    if used[idx] == u64::MAX { used[idx] = atts[i]; }
                    else if used[idx] != atts[i] { ok = false; break; }
                }
                if ok {
                    for i in 0..n { let idx = ((occs[i].wrapping_mul(magic)) >> shift) as usize; table[offset + idx] = atts[i]; }
                    return Magic { mask, magic, shift, offset };
                }
            }
        })
    };
    let rook = mk(true, &mut table, &mut rng);
    let bishop = mk(false, &mut table, &mut rng);
    Magics { table, rook, bishop }
}
fn magics() -> &'static Magics { MAGICS.get_or_init(build_magics) }
```

- [ ] **Step 3: Rewrite `negamax` multi-line + add PVS**

Replace the single-line `negamax` in `ferrum/src/search.rs` with:
```rust
    fn negamax(&mut self, b: &mut Board, depth: i32, mut alpha: i32, beta: i32, ply: i32) -> i32 {
        self.nodes += 1;
        if self.timed_out() { return 0; }
        if ply > 0 && (b.halfmove >= 100 || self.repeated(b.hash)) { return 0; }
        if depth <= 0 { return self.qsearch(b, alpha, beta); }

        let alpha0 = alpha;
        let tt_move = self.tt.probe(b.hash).map(|e| e.mv).unwrap_or(Move::NONE);
        if let Some(e) = self.tt.probe(b.hash) {
            if ply > 0 && e.depth as i32 >= depth {
                let s = from_tt(e.score, ply);
                if e.bound == BOUND_EXACT
                    || e.bound == BOUND_LOWER && s >= beta
                    || e.bound == BOUND_UPPER && s <= alpha { return s; }
            }
        }

        let mut moves = Vec::with_capacity(64);
        generate(b, &mut moves);
        order(b, &mut moves, tt_move);

        let mut legal = 0;
        let mut best = -MATE - 1;
        let mut best_move = Move::NONE;
        for m in moves {
            let u = b.make(m);
            if b.in_check(b.side.flip()) { b.unmake(m, u); continue; }
            legal += 1;
            self.history.push(b.hash);
            let s = if legal == 1 {
                -self.negamax(b, depth - 1, -beta, -alpha, ply + 1)
            } else {
                // PVS: search later moves with a null window, re-search on fail-high
                let mut s = -self.negamax(b, depth - 1, -alpha - 1, -alpha, ply + 1);
                if s > alpha && s < beta {
                    s = -self.negamax(b, depth - 1, -beta, -alpha, ply + 1);
                }
                s
            };
            self.history.pop();
            b.unmake(m, u);
            if self.stopped { return 0; }
            if s > best { best = s; best_move = m; }

    }

        | b.bb[pc(Color::White, QUEEN)] | b.bb[pc(Color::Black, QUEEN)];
    let rooks = b.bb[pc(Color::White, ROOK)] | b.bb[pc(Color::Black, ROOK)]
        | b.bb[pc(Color::White, QUEEN)] | b.bb[pc(Color::Black, QUEEN)];
    (wp | bp | n | k | (bishop_attacks(s, occ) & bishops) | (rook_attacks(s, occ) & rooks)) & occ
}

fn least_valuable(b: &Board, attackers: Bb, side: Color) -> Option<(u8, usize)> {
    for pt in 0..6 {
        let set = attackers & b.bb[pc(side, pt)];
        if set != 0 { return Some((lsb(set), pt)); }
    }
    None
}

pub fn see(b: &Board, m: Move) -> i32 {
    let to = m.to();
    let mut from = m.from();
    let mut occ = b.all();
    let bishops = b.bb[pc(Color::White, BISHOP)] | b.bb[pc(Color::Black, BISHOP)]
        | b.bb[pc(Color::White, QUEEN)] | b.bb[pc(Color::Black, QUEEN)];
    let rooks = b.bb[pc(Color::White, ROOK)] | b.bb[pc(Color::Black, ROOK)]
        | b.bb[pc(Color::White, QUEEN)] | b.bb[pc(Color::Black, QUEEN)];

    let mut gain = [0i32; 32];
    let target_pt = if m.flags() == crate::moves::FLAG_EP { PAWN } else { b.piece_on(to).map(|p| p % 6).unwrap_or(0) };
    gain[0] = SEE_VAL[target_pt];
    let mut moving_pt = b.piece_on(from).unwrap() % 6;
    let mut side = b.side.flip();
    let mut attackers = attackers_to(b, to, occ);
    let mut d = 0;
    loop {
        d += 1;
        gain[d] = SEE_VAL[moving_pt] - gain[d - 1];
        occ ^= bb(from);
        attackers &= !bb(from);
        // re-expose x-ray sliders behind the removed piece
        attackers |= (bishop_attacks(to, occ) & bishops) | (rook_attacks(to, occ) & rooks);
        attackers &= occ;
        match least_valuable(b, attackers, side) {
            Some((sq, pt)) => { from = sq; moving_pt = pt; side = side.flip(); }
            None => break,
        }
        if d >= 31 { break; }
    }
    while d > 0 { d -= 1; gain[d] = -std::cmp::max(-gain[d], gain[d + 1]); }
    gain[0]
}
```
